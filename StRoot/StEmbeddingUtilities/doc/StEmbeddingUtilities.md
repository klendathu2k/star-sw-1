# StEmbeddingUtilities

## Overview

`StEmbeddingUtilities` provides a self-contained set of classes for performing Quality Assurance (QA) on STAR Monte Carlo embedding productions. It processes minimc tree files (produced by the STAR embedding chain) alongside real µDST files, filling a comprehensive set of histograms that compare embedded simulated tracks with their reconstructed counterparts and with real-data tracks. The package is used offline—outside the normal BFC chain—to validate that the detector simulation and reconstruction response for embedded particles match that of real data, covering track kinematics, hit counts, DCA, dE/dx, and vertex resolution.

## Datasets Consumed (Inputs)

| Dataset | Description |
|---|---|
| MiniMC ROOT trees (`StMiniMcEvent`) | Per-event minimc trees from the embedding chain; contain MC truth (`StTinyMcTrack`), matched pairs (`StMiniMcPair`), ghost pairs, contaminated pairs, and matched global pairs |
| µDST files (via `StMuDstMaker`) | Real STAR µDST data; used to fill reference histograms for primary and global real tracks |
| QA ROOT output files | Previously produced embedding and real-data QA ROOT files; consumed by `StEmbeddingQADraw` for drawing comparisons |

## Datasets Produced (Outputs)

| Dataset | Description |
|---|---|
| QA ROOT file (`ana_{type}_{year}_{production}_{particleId}.root`) | Per-particle ROOT file containing all event-wise and track-wise QA histograms for either embedding or real data |
| PDF / PNG / EPS comparison figures | Generated by `StEmbeddingQADraw`; show overlay plots of embedding vs. real-data distributions for each observable |

## I/O Files

| File | Direction | Description |
|---|---|---|
| MiniMC tree file list (text) | Read | List of input minimc ROOT files passed to `StEmbeddingQA::runEmbedding()` |
| µDST file list (text) | Read | List of input µDST files passed to `StEmbeddingQA::runRealData()` |
| `ana_embedding_<year>_<prod>_<particle>.root` | Write | Output QA histograms for embedding |
| `ana_real_<year>_<prod>_<particle>.root` | Write | Output QA histograms for real data |
| `qa_<year>_<prod>_<particle>.pdf` (and optional PNG/EPS/PS) | Write | Multi-page PDF of all QA comparison plots |

## Key Dependencies

| Dependency | Role |
|---|---|
| `StMiniMcEvent` / `StMiniMcPair` / `StTinyMcTrack` / `StContamPair` | minimc data model classes for reading embedding trees |
| `StMuDstMaker` / `StMuTrack` / `StMuEvent` | µDST framework for reading real data |
| `StParticleTable` / `StParticleDefinition` | GEANT particle definitions for mass assignment and rapidity calculation |
| ROOT (`TFile`, `TH1`, `TH2`, `TH3`, `TPDF`, `TCanvas`) | Histogram management and PDF output |
| `StEmbeddingQAConst` namespace | Defines category IDs (MC, Matched, Ghost, Contaminated, MatchedGlobal, Primary, Global) |

## Typical Workflow Integration

`StEmbeddingUtilities` is run as a **standalone offline analysis**, not inside the BFC chain. A typical workflow uses ROOT macros (e.g., `StRoot/macros/embedding/runEmbeddingQA.C`) as follows:

```
(1) Run BFC with embedding → produces minimc trees + µDST
(2) StEmbeddingQA::runEmbedding(miniMcFileList)  → ana_embedding_*.root
(3) StEmbeddingQA::runRealData(muDstFileList)     → ana_real_*.root
(4) StEmbeddingQADraw(embeddingFile, realFile, geantid) → QA PDF
```

The drawing macro is invoked via:
```
root4star -b -q drawEmbeddingQA.C'("./", "qa_embedding_2007_P08ic.root", "qa_real_2007_P08ic.root", 8)'
```

## Key Classes/Functions

| Class / Function | Description |
|---|---|
| `StEmbeddingQA` | Top-level analysis class; books histograms, loops over minimc/µDST events, and fills all QA histograms per particle species and track category |
| `StEmbeddingQA::book()` | Books output ROOT file and initialises all histogram maps keyed by geant ID and track category |
| `StEmbeddingQA::runEmbedding()` | Processes a list of minimc files; fills MC, matched-pair, ghost, contaminated-pair, and matched-global histograms |
| `StEmbeddingQA::runRealData()` | Processes a list of µDST files via `StMuDstMaker`; fills primary and global real-track histograms |
| `StEmbeddingQATrack` | Lightweight wrapper around `StTinyMcTrack`, `StMiniMcPair`, `StContamPair`, or `StMuTrack`; provides a uniform interface to kinematics, hit counts, DCA, dE/dx, and nσ PID for all track categories |
| `StEmbeddingQADraw` | Reads the embedding and real-data QA ROOT files and produces overlaid comparison plots (rapidity, pT, φ, DCA, Nhit, dE/dx) in PDF and optional raster formats |
| `StEmbeddingQADraw::draw()` | Master draw function calling all sub-draws: event vertices, geant IDs, kinematics, dE/dx, DCA, and Nhit |
| `StEmbeddingQAUtilities` | Singleton providing track/event cut values, GEANT particle identification helpers, category name/ID mapping, and histogram style utilities |
| `StEmbeddingQAConst` (namespace) | Enumerates track category indices: MC(0), Matched(1), Ghost(2), Contaminated(3), MatchedGlobal(4), Primary(5), Global(6) |
