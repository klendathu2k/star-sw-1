# atlroot — ROOT Interface for STARSIM

## Overview

The `atlroot/` directory provides the **ROOT interface layer** for STARSIM (also called ATLSIM or
AUDI).  It allows the simulation framework to:

1. **Display geometry** — convert the GEANT3/ZEBRA volume tree to ROOT `TVolume`/`TGeometry`
   objects and render them in a `TCanvas` via `agconvert`.
2. **Read ROOT event files** — open a ROOT file produced by a Monte Carlo generator and iterate
   over events, filling the HEPEVT common block, via `roread.cxx`.
3. **Execute KUIP commands through ROOT** — the `aroot` class wraps a `TRint` application and
   exposes a `kuexec()` interface so that KUIP macro commands can drive ROOT from FORTRAN.

The package (~1 531 lines across 11 files) is compiled with ROOT dictionary support:
`atlrootDict.cxx` is auto-generated by `rootcint` from `LinkDef.h`, and exports `aroot`,
`agconvert`, `GtHash`, and their global instance pointers to ROOT CINT/CLING.

| `roread.cxx` | 180 | `roopen_()`, `ronext_()`, `roclose_()` | ROOT file reader for STARSIM events: `roopen_` opens a `TFileIter` on the named ROOT file; `ronext_` iterates to the next `MCEvent` dataset, unpacks `RootParticle` and `RootVertex` tables into the `hepevt_` and `hepevtd_` COMMON blocks; `roclose_` frees the `TFileIter`. |
